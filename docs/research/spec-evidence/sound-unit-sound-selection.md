## Reading rationale and caveats

0x22490 initializes kind and class from the unit, calls import thunk 0xC65E, and invokes thunk 0xC658 only for kind zero. It returns the class local. The label suggesting a sound id is unsupported. The companion accessors return kind and mode using the same conversion machinery. Import resolution gives D2Common ordinal 10175 at 0x2F1B0 and ordinal 10350 at 0x501E0. The latter's entry tests a unit flag and begins a table-driven conversion; its remaining path is unread.

0x22A70 first resolves effective class, checks a source count, and examines monster data flags. A first alternate path consults an imported record and its +0x18 field. A later path tests another monster flag or local helper 0x4C0D0, then reads a signed word at +0x16 from another imported record. Positive values use the direct lookup, otherwise the indirect lookup. The meanings of those flags and record fields are not established by column names.

The direct imported lookup validates table presence, nonnegative index and count, then selects a 0x94-byte record. The indirect lookup validates two tables and the upper class bound, reads a signed word at source-record stride 0x1A8 plus 0x14, then validates the resulting sound-record index. This does not prove the tables' names, nor make original memory strides a behavioral requirement. Import thunks 0xCABA and 0xCF76 resolve respectively to ordinal 10876 / 0x52FF0 and ordinal 10917 / 0x52FA0.

0x22CA0 requires effective kind one and a non-null selected record. Selector 8, 9, 10, 11 chooses dwords at +0x44, +0x48, +0x4C, +0x50 respectively. Other selectors return. Cue 0xA84 requires unsigned current tick minus the unit's +0x7C value to be at least 25; other zero cues return. The request passes three zeros and the unit to 0x88A70 with the selected cue in a register, then stores the current tick to unit +0x7C and shared 0x11C4C4. Actual cue binding and argument semantics remain gated.

0x23C00 includes kind/mode eligibility, special class checks 15 and 110, signed animation field +0x4C, initial factor 2 and default chance 100. Selected record fields +0x58/+0x5C/+0x60/+0x64 replace secondary cue, factor, phase displacement and chance candidates. It computes phase comparisons through 0x895D0 and requests through 0x22FB0 then 0x88A70. After primary request success it sets a result-dependent value through 0x87ED0; a secondary request can consume a random draw via 0x89640. Those local callees and producer mappings are not fully read, so arithmetic and seed order are not verified.

The 0x22C10 original-image disassembly confirms a shared unsigned elapsed-tick threshold of 4, one inline random step modulo 3 and selector addition 6, record field +0x78, then timing writes. The loader binds +0x78 to `Flee`, so the label suggesting random footsteps is misleading. 0x22070 and 0x220A0 store/read unit +0x7C despite their graphics-related labels.

### Identity and record producers

The three client accessors convert identity only when the original unit kind is player (0). They initialize absent identity to kind 6 and class -1, obtain the mode from D2Common #10175, and call #10350 / 0x501E0 for original players. The generic conversion's monster-to-player arm therefore does not imply that these client accessors convert original monsters. The conversion requires unit flag bit 3, a supported original kind, an eligible extended state list with its high flag bit set, and active state membership. It examines the prepared disguise list in order and uses the first active record with gfxtype 1 or 2. The previously recorded graphics-class and mode mappings apply. D2Common 0x5DA30 prepares ascending signed state indices selected by flag index 16. Its complete encoded instructions were corroborated against the original image; import thunk 0x9222 resolves to FOG #10045 / 0x1CD50. That allocation wrapper was read through its allocator and failure-report delegation; allocator internals remain a separate resource boundary. Additional cache-setting paths at 0x52660, 0x32CA0 and 0x1AA00 were read. Complete 0x38730 and its overlap predicate 0x33C20 were read and native-decoded: a changed state membership bit marks the update bitset; enabling a disguise state sets unit flag bit 3, while disabling it clears that flag only if no active state overlaps the prepared disguise mask. The mask builder 0x5DAD0 iterates States records and sets their state-index bits for each requested flag. Loader 0x5F6E0 builds 40 such masks; flag 16 supplies the mask at DataTables +0x10C. These close the identified mask/cache computation chain, while full state-list initialization, upstream state mutation entry coverage and transformed runtime cases remain open.

The default/alternate sound table family is now bound. D2Common #10038 is 0x53370 (matched C), reading the table published by 0x59870 from superuniques, record stride 0x34. Its +0x18 field is the loader's MonSound descriptor and uses the MonSounds linker. The MonStats loader 0x5AA40 binds +0x14 to MonSound and +0x16 to UMonSound with that same linker. Descriptor strings and destinations were read from the original image; generic loading retains GDA-R02/GDA-R03d limits.

Client 0x22A70 returns direct MonSounds index 0 for an absent unit or an effective class at least the MonStats count. ### Complete movement computation read

For effective monsters, 0x23C00 normally admits modes 2 and 15. Effective class 15 additionally admits mode 1; class 110 replaces that test with mode 8. Other effective kinds bypass this monster-mode gate. Zero signed 16-bit animation speed returns. Defaults are factor 2, phase offset 0, secondary cue 0, chance 100. A selected monster record replaces these with FsCnt, FsOff shifted left 8, FootstepLayer and FsPrb; zero FsCnt returns.

Let L be the unsigned animation length, S the sign-extended speed, F the factor, P the unsigned quotient L/F, Q the unsigned quotient L/low32(F*S), A the current animation progress, and O the shifted offset. The routine's actual unsigned divisions require valid nonzero divisors; no normal fallback for divide faults is established. Elapsed time is wrapping unsigned subtraction of the prior movement tick from the captured current presentation tick. When F is unsigned-greater-than 1, elapsed below floor(low32(2*Q)/3) returns. The current wrapped phase distance must be strictly less than both distances at low32(A+S) and low32(A-S); equality returns. The wrapped-distance helper uses signed remainders for non-power-of-two periods and masks for power-of-two periods, including its zero-period mask case; intermediate differences and absolute values retain 32-bit behavior.

The primary base is MonSounds.Footstep for effective monsters or the original seven-player-class executable table for players: classes 0..6 respectively use 2768, 2720, 2720, 2768, 2816, 2720, 2720. Material selectors 1..6 add respectively 0, 4, 8, 12, 16, 20, and the run flag adds 24. The environment fallback now binds to SoundEnviron.Material 1: client 0x5DFD0's descriptor writes +0x1C, with its original string at 0xD5524. Tile metadata is tested before that fallback with priority masks 0x20, 0x08, 0x10, 0x40, 0x80, 0x400 returning selectors 1, 2, 3, 4, 6, 5. The tile-library metadata origin was subsequently followed as recorded below; friendly material names beyond the numeric selector contract remain unassigned.

The primary request passes the selected cue, emitter and three zero auxiliaries. A nonzero return gets volume 255 for the local player, otherwise 200. Elapsed strictly above floor(low32(3*Q)/2) changes these values to 160 and 125 respectively. A nonzero FootstepLayer independently draws from the local-player presentation seed modulo 100 and requests that cue if the unsigned draw is below FsPrb, even when the primary request returned zero. Finally the captured admission tick is written to the unit movement tick. This path does not write the shared cue tick. Playback admission and the volume setter's downstream effects retain their separate sound-owner boundary.

The complete 0x22C10 computation requires effective monster and a present record, then unsigned shared elapsed time at least 4. It consumes one local-player presentation-seed step modulo 3 and adds 6 as the request's delay argument. It forwards the unchanged Flee cue, including zero or negative identities, and two remaining zero auxiliaries. It ignores the return and performs the ordered unit/shared cue-tick writes. The random value is a delay, not an addition to the cue identity; the prior candidate wording about a cue variant was insufficiently precise. Full event-17 production and playback integration remain gated.
